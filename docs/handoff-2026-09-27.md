## What Is InvestiGate

An **agentic RAG system for Indian equity research**. It reads a real brokerage portfolio, grounds analysis in primary source documents (annual reports, filings, earnings-call transcripts), and produces a portfolio review where every number is traceable to a deterministic source and every qualitative claim carries a citation.

**Dual purpose:**
- **Product goal** — replace manual, one-stock-at-a-time research with a standing portfolio review tool
- **Learning goal** — build retrieval, evaluation, and agentic infrastructure from primitives as demonstrable AI engineering depth

### 3. RAG Architecture Explained & Documented
Clarified for the user (who is learning agentic AI) where RAG fits:
- RAG is **not** "talk to my portfolio" — numbers come from APIs deterministically
- RAG is for **governance data buried in PDFs** that no API exposes: auditor qualifications, promoter pledging, related-party transactions, contingent liabilities
- System has **two modes**: ingestion (batch, periodic — fetch PDFs from internet → parse → chunk → embed → index) and query (interactive, fast — hits already-built index)

### 4. Financial Data Breakdown Prepared for Finance Review
User is getting the financial aspects reviewed by finance people. A detailed breakdown was provided covering:

**Stream 1 — Structured (API, no RAG):** CMP, P/E, EV/EBITDA, P/B, margins, D/E, dividend yield, analyst targets, plus derived values (allocation %, gain/loss, concentration) computed in Python never by LLM.

**Stream 2 — Unstructured (fetched from internet → RAG):**
- **Annual Reports:** Auditor's report (qualified opinions, emphasis of matter, key audit matters), related-party transactions, promoter pledging, contingent liabilities, accounting policy changes, board composition, auditor changes/resignations, segment reporting
- **Quarterly Shareholding Patterns:** Promoter holding % change, pledging %, FII/DII changes
- **Earnings Call Transcripts:** Management guidance drift detection across quarters, capex delivery tracking
- **Corporate Announcements (later):** Board outcomes, credit rating changes, insider trades

## Key Design Decisions (Context for New Chat)

| Decision | Rationale |
|----------|-----------|
| Numbers never embedded in vectors | Structured data fetched deterministically; vector search over numbers degrades precision and increases hallucination |
| No LangChain/LlamaIndex in retrieval path | Learning project — must survive interview probing; `.as_query_engine()` is a bad answer. LangGraph orchestrates, does not retrieve. |
| pgvector + Elasticsearch over Pinecone | Self-hosting teaches HNSW tuning; Pinecone already on resume |
| Separate red-team critic call | Self-critique within single generation is measurably weaker |
| Grounding validator is code, not prompt | Hard gate: every number must trace to structured payload, every citation to a real retrieved chunk |
| OpenAlgo for broker integration | 34+ brokers supported, InvestiGate never handles credentials |
| LangGraph over Temporal | Career goal is agentic AI; LangGraph is what the market asks for |
| Documents fetched from internet | User won't have reports locally; system must fetch from BSE/NSE/company IR pages, then ingest |
